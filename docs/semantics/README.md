# 模型语义与教学路线

模型配置先生成带语义的计算图，再投影为结构图、2D 或 3D。布局不改变计算依赖；教学播放可以省略步骤，但会明确标记，完整逐层路线仍保留全部主干调用。

## 张量与节点

`Tensor.axes` 标注 batch、query、key、head、kv-head 和 feature 轴，`Tensor.role` 区分 scores、probabilities、context、query、key、value 和状态。适配器原有的显示符号在 `tensor-semantics.ts` 中统一转换，渲染器和数值查看器共用坐标读取函数。矩阵末两轴对应行列，固定的其他轴在面板中显示完整切片坐标；token/head 选择改变相应切片，未记录位置不补值。Head 选择范围来自当前张量：GQA 的 K/V 使用 KV 头数，Query 使用 Query 头数；切换张量后越界选择会重置到有效范围。矩阵分页也随当前张量尺寸限制。

节点的 `linear` 显式描述线性变换输入输出宽度，与后续 head reshape 分开。例如 Qwen3 MoE 的 Q 投影 `2048 → 4096`，即使输出布局为 `[B,32,S,128]`，矩阵也按正确的扩张方向展示。

`attention` 描述当前层的查询/键长度、全局位置偏移、头数与窗口。Gemma 的本地张量索引与历史 token 位置分开，局部/全局层使用各自规则。无法从配置确定的压缩候选、稀疏索引只显示未知结构，不生成确定的访问热图。Context 记录只驱动 Context 向量，不用于恢复注意力概率。

`parameterStatus` 区分已知、估算和未细分。通用 Attention 的 Q/KV/展开/O 投影，以及 FFN 的路由、专家、共享分支、上下投影按现有参数公式拆分；不能细分的节点显示“未细分”，不会把占位 0 宣称为零参数。复杂架构仍保留原有部分估算范围。

## 子图展开

Attention/MLP 子图提供主输入与主输出端口；历史 KV 等额外输入保持独立。`buildDemoWorld` 依据原图边连接端口，父节点仅作摘要，不额外执行。并行 Attention 与 FFN 保持并行，不因为列表相邻而增加依赖。

通用 Attention 图显式展示当前 KV 投影、历史 KV、缓存更新和可见 KV；MLA 的逻辑展开单列，融合后端不一定实际分配展开张量。

## 运行记录

原有 version=1 记录增加可选 `instance` 字段，表示层图中父模块的节点 ID。同一层有两次 Attention 时必须指定它，例如 LongCat 的 `mixer` 和 `lc-attn1`；同一节点两次执行可分别记录。只有一个候选父模块的旧记录会自动补齐 instance，多候选的歧义记录会被拒绝。

```json
{
  "pass": 0,
  "loop": 0,
  "layer": 0,
  "view": "attention",
  "instance": "lc-attn1",
  "nodeId": "q-proj",
  "direction": "output",
  "tensorIndex": 0,
  "shape": [1, 32, 4, 192],
  "indices": [[0, 0, 0, 0]],
  "values": [0.25]
}
```

采样坐标在首次查询时建立索引；场景切换保留同一份索引，避免每个可视单元重新扫描整个记录。二维矩阵与三维向量使用相同记录颜色：绿色表示正值、红色表示负值、浅灰表示零、深灰表示未记录。真实采样不在相邻坐标之间插值，教学示意色带保留渐变。

上例仅说明格式，是合成样本。实际 shape 必须与所选配置和场景一致。总览、层级记录不指定 instance。导入记录自动使用完整逐层路线；更改提示长度或缓存模式会移除原记录，避免场景与记录不一致。

## 默认教学路线

默认“代表层讲解”，4 个提示位置、2 轮输出。Prefill 展示代表层的主要计算及最多三个异构边界，下一轮用摘要展示前向与输出；未逐项展示的计算会标注省略。标准速度下现有 111 个模型的默认路线预算均不超过 5 分钟。此时间是阅读预算，与真实推理性能无关。

“完整逐层”保留所有实际层和循环调用。指定某个层进行精确探索时自动进入完整路线。开始前和时间轴显示预计总时长，可改变节奏和速度。每个步骤在计划生成时记录基础时长，调速和切换节奏只缩放时长，不重建计算图；同一层内 Attention/MLP 的切换复用完整层场景。2D/3D 切换保留所选子模块的语义身份，浏览位置与播放位置分别维护。

## 校验

导入配置在修改应用状态前检查配置、参数总量、输入场景、总览图和缓存报告，失败时保留当前模型。通用模型校验任务头、归一化常数、层类型及循环上限；Grok 的公开配置以 `sliding_window_size=-1` 表示关闭窗口，作为显式架构约定接受。

回归检查包括非法导入后的恢复、并行依赖等价、各层窗口和坐标、投影与缓存端口、已知参数分项、两种张量轴顺序、融合 Context 与概率区分、重复子层记录身份、跨视图定位和默认路线时长。
