# 默认模型与全屏查看

工作台和直接进入的推理演示默认加载 DeepSeek V4.1 Flash；默认配置、源仓库及模型库当前卡片保持一致。

工作台显示工具栏与推理演示顶部均提供「全屏查看 / 退出全屏」按钮，支持浏览器原生全屏与 Esc 退出。不支持或拒绝原生全屏时使用铺满当前窗口的模式。按钮的图标、标题与按下状态同步浏览器全屏事件。

工作台全屏收起摘要与侧栏；仍可按需打开模型与详情面板，退出时恢复进入前的侧栏状态。3D 画布保持挂载，播放进度、模型、token 和缓存状态不因全屏切换而重置。演示中可以在全屏状态下切换模型。

验证覆盖默认身份、三种工作台视图、进入 / 退出、外部全屏退出事件、恢复焦点与侧栏、暂停进度不变、全屏模型切换，以及 360px 下的替代模式。测试：`tests/fullscreen.spec.ts`。全量单元测试 1022 项通过，生产构建和生产页面实际全屏验证通过。相关 66 项浏览器回归在修复测试的手机模型选择器和 3D 聚焦距离后，全部通过（58 项首轮 + 8 项修复后复查）。
